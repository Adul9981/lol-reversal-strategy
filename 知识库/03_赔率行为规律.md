## V 型结构：赔率下跌→反弹

我们检测了以下参数组合下的V型信号：
- 下跌幅度 ≥ 25%（从局部高点到当前）
- 反弹幅度 ≥ 10%（从底部回升）
- 反弹持续时间 ≥ 5分钟

**结果**：
```
有V型信号场次：  243/361 = 67%（覆盖率太高，信号无选择性）
信号弱势方胜率：  22%（低于基础率28%）
```

**结论**：当前参数下的V型信号没有有效提升命中率，反而更差。

**可能原因**：
1. 阈值太宽松（67%覆盖率意味着几乎所有比赛都有V型）
2. 很多「V型」只是赛前随机波动，与比赛进程无关
3. 真正有价值的信号是赔率「从高位快速深跌后反弹」，而不是任何幅度的波动

⚠️ **待优化**：需要更严格的参数，或引入「比赛内特定事件触发」的信号逻辑

## 赔率分层的关键阈值

根据02文档的数据，赔率行为呈现明显的分层结构：

```
赔率区间      市场行为解读
────────────────────────────────────────────
> 50%         强势方，不是反转目标
30-50%        弱势方正常水平，赛前合理定价
20-30%        弱势方处于劣势，但仍有正常翻盘空间
10-20%   ★   「危机但可救」区间，反转率接近100%
5-10%    ★   「深度危机」区间，反转率~89%，对应较高赔率倍数
< 5%          「几乎已定局」区间，反转率0%，不可交易
```

★ = 当前数据下的可交易区间

## 赔率下跌速度（待研究）

⚠️ **以下为假设，尚未有数据验证**

我们观察到两种赔率下跌模式：

**模式1：渐进式下跌**（非恐慌）
```
30% → 25% → 20% → 18% → 15% ...（每局输后正常调整）
```
- 可能反映真实战局恶化
- 市场在合理定价

**模式2：急跌式下跌**（可能恐慌）
```
30% → 28% → 10% → 8%（短时间内急速下跌）
```
- 可能是大额下注/数据源误判/临时性事件导致
- 市场可能存在过度反应
- 这种情况下的反弹信号可能更可靠

**需要验证**：急跌（如5分钟内跌幅>50%）之后的反转率是否高于渐进下跌？

## 时间窗口规律（初步观察）

从已有样本观察到的规律（未统计，待验证）：

1. **BO3中**：赔率最低点通常出现在G2进行中（落后方输了G1，G2又在落后）
2. **BO5中**：赔率最低点通常出现在0-2落后时的G3，或0-3时的G4
3. **触底后反弹**：往往发生在「关键团战/大龙争夺」之后约20-30分钟

这些观察是从少量样本案例里得到的，不能作为统计结论。

## 赔率历史访问的技术细节

```python
# 有效请求方式（已验证）
url = "https://clob.polymarket.com/prices-history"
params = {
    "market": token_id,   # clobTokenId（token_0对应outcome_0）

# 返回格式
# {"history": [{"t": 1779376805, "p": 0.55}, ...]}
# t = Unix timestamp, p = price (0-1)
```

注意：
- 同一比赛有两个token（一个给team0，一个给team1），价格之和约等于1（有时有微小价差）
- 只需拉取其中一个token即可，另一个价格 ≈ 1 - p
