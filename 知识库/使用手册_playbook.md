## 整体执行流程一览

```
① 监控赔率          ② 触发条件检查        ③ 战局状态核查        ④ 下单/放弃
   （持续）         （赔率跌到阈值时）      （实时看 Livestats）    （30秒内决定）

 赔率 < 15%？  →  时间在 20-35 分？  →  金币差 / 龙 / 核心  →  全部满足→买
                                                               任一不满足→放弃
```

## 指令一：确定监控哪些比赛

**操作步骤**：
1. 打开 Polymarket，搜索「Game Winner」，筛选 LCK 或 LEC 正在进行的比赛
2. LPL 比赛需要你主观判断是否有异常操作迹象，再决定是否监控
3. LCS 基本跳过（翻盘率极低，彩票机会稀少）

**背后的思考**：
- 我们有 240 局数据分析，LCK 翻盘率 24%，LEC 21%，LCS 仅 14%
- LPL 翻盘率 20%，但存在选手操作异常疑虑（假赛风险），无法纯粹依赖数据判断
- 决策：优先 LCK + LEC，LPL 留给主观判断，LCS 不值得花时间

**已知局限**：
- 只有 2026-04 至今约 3 个月数据，联赛可信度结论可能随赛季变化
- LPL 假赛没有客观判断标准，完全依赖主观经验

**优化记录**：
- v1.0：LCK + LEC 优先，LPL 主观，LCS 跳过

## 指令二：判断是否触发「考虑买入」

**操作步骤**：
看到某队赔率满足以下**全部**条件，才进入下一步：

```
条件 1：当前赔率 ≤ 20%（彩票型目标 ≤ 10%）
条件 2：当前游戏时间 在 15–35 分钟之间
条件 3：联赛为 LCK 或 LEC（或你判断 LPL 本场无异常）
```

**如何知道当前游戏时间**：
- 看直播（最直接）
- 看 Polymarket 赔率首次出现大幅下跌的时间点，估算游戏进度
- 用 LoL Esports 网站确认比赛开始时间，加上经过的分钟数

**背后的思考**：
- 数据发现：触底时刻是最关键变量。20-30 分钟触底的 EV = +0.25（@<10%），10-20 分钟触底 EV = -0.41
- 为什么是「当前时间」而不是「触底时刻」：Polymarket 每 10 分钟更新一次，你看到低赔率时，可能距实际触底已经过了 0-10 分钟。无法实时确认「这就是底部」，只能用「现在时间」作为代理
- 15 分钟下限：10-15 分钟内的低赔率多为开局雪球，市场定价准确，不值得买
- 35 分钟上限：超过 35 分钟游戏进入高地攻防，翻盘窗口基本关闭

**已知局限**：
- 游戏时间需要你自己看直播或估算，有 ±3-5 分钟误差
- 「触底」是事后概念，实战中不知道赔率是否还会继续跌

**优化记录**：
- v1.0：15-35 分钟窗口，基于 140 个案例（翻盘 28 + 未翻 112）

## 指令三：核查战局状态（核心决策步骤）

**操作步骤**：
打开 Livestats 数据，检查廉价队（赔率低的那队）当前状态：

```
必须同时满足：

  ✅ 金币差 > -3000
     （廉价队落后不超过 3000 金）
     → 最强单一过滤条件：满足此条件在20-30min窗口内胜率35.1%，EV +2.51

  ✅ 对方龙数 ≤ 2（且未获得龙魂）
     （对方离龙魂还有距离，战力差距未定型）
     → 已从 ≤3 更新为 ≤2：对方3条龙时下一条即龙魂，风险激增，不值得博

  ✅ 廉价队水晶未被推（对方水晶 = 0）
     → 安全底线条件：极少有水晶被推的案例能翻盘，数据已验证

加分项（满足 ≥ 1 个，进一步提高信心）：

  ⭐ 廉价队有「存活核心」：至少 1 名选手死亡 ≤ 1 次 且 击杀参与（kills+assists）≥ 3
     → 三合一组合（金差>-3000 + 龙≤2 + 有核心）：胜率33.3%，EV +2.33（n=24）

  ⭐ 廉价队刚获得或即将获得大龙/男爵（20-25 分钟男爵刷新节点）
     → 男爵资源直接转化为一波推线 / 团战优势，是最常见的翻盘触发器
```

**如何查看 Livestats 数据**：
- 方式 A（推荐）：看带数据覆盖的专业直播（如 Twitch 的 LoL Esports 官方台，数据面板）
- 方式 B：使用 LoL Esports 官网比赛页面的实时数据
- 方式 C（进阶）：直接调用 API：
  ```
  GET https://feed.lolesports.com/livestats/v1/window/{game_id}?startingTime={现在时间}
  ```

**背后的思考**：
- 为什么用「当前帧」而不是等「触底帧」：当前 Livestats 是实时的，可以立即看到；触底帧需要事后才知道是哪一帧
- 当前帧比 Polymarket 赔率早 0-10 分钟，信息实际上更新，这是优势
- 金币差阈值 -3000：Script 12 深度扫描（n=140）确认，在20-30min窗口内使胜率从23.1%→35.1%（EV +2.51，Wilson下界 +1.36）。这是所有单一指标中效果最强的。
- 龙数从 ≤3 改为 ≤2：组合条件分析显示「对方龙≤2」与金币差配合时 EV 更高；且从博弈角度，对方3条龙时下一条是龙魂，战力提升不成比例
- 「存活核心」来自你的实战观察，数据支持：翻盘局67.9%有核心，未翻57.1%。作为加分项而非硬条件，是因为单独筛选胜率提升不显著（22.9% vs 20%基础）
- 死亡集中度：Script 12确认与翻盘无关（两组分布完全相同），已从加分项中移除

**已知局限**：
- 金币差 -3000 的阈值是基于 28 个翻盘案例的平均值推算，样本量偏小
- 战局数据需要自己手动查看，有时间成本（约 30-60 秒）
- Livestats API 需要知道 game_id，自动化前需要手动获取

**优化记录**：
- v1.0：三个必须条件 + 三个加分项，基于初步分析（28 翻盘 vs 112 未翻）
- v1.1（Script 12 后）：
  - 龙数条件从 ≤3 更新为 ≤2（更精准）
  - 水晶条件收紧：从「≤1个」到「= 0」
  - 移除「死亡集中度」加分项（数据证明无效）
  - 加分项「存活核心」补充具体数据支持（67.9% vs 57.1%）

## 指令四：决定买多少

**操作步骤**：
```
彩票型（赔率 ≤ 10%）：单次买入 = 总资金 × 0.5%–1%
深度型（赔率 11–20%）：单次买入 = 总资金 × 1%–2%
稳健型（赔率 21–30%）：单次买入 = 总资金 × 2%–4%

例：总资金 $500
  彩票型：每次 $2.5–$5
  深度型：每次 $5–$10
```

**背后的思考**：
- 使用 1/4 Kelly 准则（而非全 Kelly），因为我们的样本量还不够大，胜率估计有误差
- 彩票型预期连续失败 8-10 次，必须控制单注金额避免心理崩溃
- 目标：10 次彩票型买入里哪怕只有 1 次翻盘，就能覆盖其余 9 次损失并盈利（@10% 买入，1 次赢回约 $50，覆盖 9 次各 $5 损失后还剩 $5 利润）

**已知局限**：
- Kelly 准则依赖准确的胜率估计，目前胜率样本量小（n=24-60），建议保守执行
- 没有设置止损（彩票型），因为买入成本本身就是最大损失

**优化记录**：
- v1.0：1/4 Kelly，分三档

## 指令五：持仓管理和止盈

**操作步骤**：

```
买入后：
  ① 如果 30 分钟内赔率没有任何回升迹象 → 接受亏损，不再加仓
  ② 如果赔率从买入价涨至 3-5 倍 → 卖出 50%，剩余持有到结算
  ③ 如果赔率跌破买入价再下跌 20% → 这可能是「假底」，观察但不加仓

常见情况：
  买 $0.10 → 涨到 $0.40（4x）→ 卖出一半，剩余持有等结算
  买 $0.10 → 涨到 $1.00（结算）→ 全部收益
  买 $0.10 → 归零 → 全额损失，这是预期内的
```

**背后的思考**：
- 数据显示触底后等待时间 P90 = 30 分钟，即 90% 的案例在买入后 30 分钟内结束
- 彩票型不需要止损：买入价就是最大损失，要么赢，要么归零
- 为什么 3-5 倍时卖一半：锁定部分利润，但保留上行空间。不需要等到 $1.00 结算，市场价格接近 $0.40 时翻盘已基本确认
- 你提到「执行力不强」：卖出一半的策略降低了「拿着不动还是卖」的心理压力

**已知局限**：
- 「3-5 倍」止盈点没有数据支撑，是经验判断
- Polymarket 有买卖价差，实际卖出价可能低于显示价格

**优化记录**：
- v1.0：30 分钟持仓上限，3-5 倍卖出一半

## 关于 Livestats API（进阶使用）

如果你想用 API 直接查，流程是：

```python
# 1. 获取 game_id（从 LoL Esports API 的比赛详情）
# 2. 获取当前时间戳（整除 10 秒）
import requests
from datetime import datetime, timezone

game_id = "你的游戏ID"
now = int(datetime.now(timezone.utc).timestamp())
now = (now // 10) * 10  # 必须整除 10 秒
ts = datetime.fromtimestamp(now, tz=timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.000Z")

r = requests.get(
    f"https://feed.lolesports.com/livestats/v1/window/{game_id}",
    params={"startingTime": ts},
    headers={"x-api-key": "0TvQnueqKa5mxJntVWt0w4LpLfEkrV1Ta8rQBb9Z"},
    verify=False
)
frame = r.json()["frames"][0]
blue = frame["blueTeam"]
# blue["totalGold"], len(blue["dragons"]), blue["inhibitors"], blue["towers"]
```
