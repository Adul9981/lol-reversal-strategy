## 核心思路

选手实力作为**修正因子**（不是独立入场条件）：
- 赔率信号 + 战局信号 → 决定是否入场
- 选手实力差 → 决定**仓位大小**和**信心权重**

## 量化方案（三层模型）

### 第一层：赛季积分/排名差（基础强度）

```python
# 核心位置：打野 + 中单（两者加权平均）
# 数据：当前赛季各联赛排行榜
实力差 = 弱势方(打野积分 + 中单积分) - 强势方(打野积分 + 中单积分)
```

分级：
- `实力差 > +5`：弱势方核心比对方强 → 支持反转，加权
- `实力差 -3 ~ +5`：双方接近 → 中性，不加不减
- `实力差 < -5`：弱势方核心更差 → 降权，减少仓位

### 第二层：本赛季个人数据（发挥状态）

用 Oracle's Elixir 数据计算赛季综合分（每位选手）：

```
个人得分 = 
  KDA              × 0.25
  伤害占比(DPM)    × 0.30   # DPM / 全队DPM
  经济占比(GoldShare) × 0.25
  参团率(KP%)      × 0.20
```

**用途**：区分「这场表现差是失常」vs「赛季本来就这水平」

### 第三层：历史交手记录（克制关系）

```
历史胜率 = 弱势方在过去12个月对强势方的胜场数 / 总交手场数
```

- 如果弱势方历史胜率 > 50% → 存在战术克制优势，支持反转
- 如果弱势方历史胜率 < 30% → 存在心理劣势，降权

---

## 聚焦点：打野 + 中单

为什么只看这两个位置：
1. 打野决定全图节奏和资源分配，对翻盘影响最大
2. 中单通常是核心输出，且活跃于全图
3. 上单/辅助更依赖当局英雄选择，量化难度更高
4. 射手稳定性相对高，个人差距体现不明显

## ❓ 存疑问题

1. **积分跨联赛比较是否合理？**  
   LCK第10名 vs LPL第10名，谁更强？不同联赛的积分体系不一样，直接比较可能失真。  
   → 可以考虑只在同联赛内比较，跨联赛用Elo评分体系转换

2. **「失常」还是「真的弱」怎么区分？**  
   一个高KDA选手某场KDA为0/5/2，是发挥失常还是对位被克制？  
   → 需要结合当局英雄信息，但这超出了简单量化范围

3. **数据更新频率问题**  
   赛季中期数据和赛季末数据代表性不同（刚开赛时样本少）  
   → 建议只用「最近20场」的滑动窗口数据
