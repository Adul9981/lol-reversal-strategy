# Web UI 产品需求文档
# LoL Polymarket 自动交易系统

---

## 概览

**平台**：桌面端网页（主要），响应式兼容移动端  
**交互模式**：可在「手动交易」和「自动交易」之间切换  
**页面数量**：3 个页面 + 全局顶栏

---

## 全局顶栏（所有页面常驻）

```
[LOGO]   今日赛程  |  比赛详情  |  账户总览      手动 ⇄ 自动      余额: $847 USDC    今日盈亏: +$43    [一键暂停]
```

| 元素 | 说明 |
|------|------|
| 页面导航 | 三个页面切换 |
| 手动 ⇄ 自动 | 切换交易模式，切换时需二次确认弹窗 |
| 余额 | 当前 Polymarket 账户 USDC 余额，实时 |
| 今日盈亏 | 正数绿色，负数红色 |
| 一键暂停 | 暂停所有自动交易信号，按钮变红并显示「已暂停」 |

## 页面一：今日赛程

### 布局

页面标题显示当前日期。以列表形式展示今日所有 LCK / LPL / LEC / LCS 比赛，按开始时间排序。

### 每行比赛信息

```
状态标签    队伍 A  vs  队伍 B    联赛    赛制      信号强度    本场盈亏    操作
──────────────────────────────────────────────────────────────────────────
🔴 直播中   KT vs Dplus KIA     LCK    BO5 · G3    ⭐⭐⭐      —         [查看]
🔴 直播中   T1 vs BFX           LCK    BO3 · G1     —         —         [查看]
⏰ 45分后   Gen.G vs HLE        LCK    BO3           —         —
✅ 已结束   DK vs NS            LCK    BO3 · G2    触发过     +$28
✅ 已结束   JDG vs BLG          LPL    BO3           —          —
```

| 字段 | 说明 |
|------|------|
| 状态标签 | 直播中（红点动画）/ 距开始时间 / 已结束 |
| 信号强度 | 实时信号：⭐⭐⭐ / ⭐⭐ / ⭐；已结束场次显示「触发过」或「—」 |
| 本场盈亏 | 有交易才显示，正绿负红 |
| [查看] | 跳转到页面二，展示该场比赛详情 |

### 交互

- 直播中的比赛置顶
- 有信号触发的行高亮（浅黄色背景）
- 点击任意行跳转页面二

## 页面二：单场比赛详情

### 页面顶部：比赛基本信息

```
← 返回    KT Rolster  vs  Dplus KIA    LCK · BO5 · Game 3    第 23 分钟
                35¢                         65¢
```

显示双方当前赔率，大字号，颜色区分（低赔率方用红色或橙色）。

---

### 区域 A：赔率走势图

- 横轴：游戏时间（分钟），0 到当前时刻
- 纵轴：赔率 0% - 100%
- 两条折线：队伍 A（蓝）和队伍 B（红）
- **标记点**：
  - 🔔 信号触发时刻（三角形标注，悬停显示：触发原因、当时金差、当时赔率）
  - 💰 实际买入时刻（圆形标注，悬停显示：买入价、买入金额）
- 图表右侧实时滚动更新

---

### 区域 B：当前战局数据

两列对比，居中展示金差。

```
              KT              DK
金币         42,300    |    44,800     差值：-2,500  ✅
击杀            8      |      11
防御塔          4      |       5

高地状态       完好    |     完好                   ✅
```

| 指标 | 达标标准 | 图标 |
|------|---------|------|
| 金差 | 落后方差值 < 3,000 金 | ✅ / ❌ |
| 小龙 | 领先方龙数 ≤ 2 | ✅ / ❌ |
| 高地 | 落后方高地未失守 | ✅ / ❌ |

**所有条件满足时**：区域 B 整体显示绿色边框。  
**任意条件不满足**：对应行变红，区域整体不高亮。

### 区域 C：信号与操作

#### 自动交易模式

```
┌─────────────────────────────────────────────────────────┐
│  ⭐⭐ 信号触发 · 第 19 分钟                              │
│  已自动买入：KT Rolster  $30  @ 21¢                     │
│  当前估值：$30 → $41（+$11，+37%）  [一键平仓]          │
└─────────────────────────────────────────────────────────┘
```

- 若暂未触发信号：显示「监控中，条件未满足」及哪些条件未达标
- [一键平仓]：手动强制卖出当前持仓，需二次确认

#### 手动交易模式

```
┌─────────────────────────────────────────────────────────┐
│  ⭐⭐ 信号触发  条件全满                                  │
│                                                         │
│  买入 KT Rolster：金额 [____$30____]  @ 当前 23¢  [买入]│
│  买入 Dplus KIA ：金额 [____$30____]  @ 当前 77¢  [买入]│
│                                                         │
│  LCK A型额度剩余：$0（今日已用满）⚠️                    │
└─────────────────────────────────────────────────────────┘
```

- 金额输入框预填 M1 建议上限值
- 额度不足时按钮置灰并显示警告
- 点击[买入]弹出确认弹窗（显示：队伍、金额、当前赔率）

## 交易模式说明（给开发参考）

| 模式 | 信号触发后的行为 |
|------|----------------|
| 手动 | 发出通知，在页面二区域 C 展示买入按钮，等待用户操作 |
| 自动 | 满足所有条件后直接调用 Polymarket CLOB API 下单，页面展示结果 |

**自动模式的保护机制（必须实现）**：
- 每日总亏损超过 $X（可配置）→ 自动暂停，发送通知
- 单笔超过 M1/M2 上限 → 拒绝下单
- Polymarket API 连续失败 3 次 → 自动暂停，报警
