# 服务器部署指南

> 总时间约 15 分钟。分两部分：你做4步，然后我帮你跑脚本。

---

## 你需要做的 4 步

### 第 1 步：租服务器（5分钟）

1. 打开 [https://www.hetzner.com/cloud](https://www.hetzner.com/cloud)
2. 点 **Sign Up**，用邮箱注册（需要信用卡/PayPal，€4.5/月）
3. 登录后点 **New Project** → 随便取个名字
4. 点 **Add Server**，按以下选项配置：
   - **Location**: 选 Helsinki 或 Singapore（离亚洲近延迟低）
   - **Image**: Ubuntu 24.04
   - **Type**: Shared CPU → **CX22**（2 vCPU / 4GB RAM，€4.5/月足够）
   - **SSH Keys**: 点 Add SSH Key，粘贴你的公钥（终端运行 `cat ~/.ssh/id_rsa.pub` 获取）
   - 如果没有 SSH key，选 **Root Password** 模式，设一个密码
5. 点 **Create & Buy Now**，等 30 秒服务器就好了
6. 记下服务器的 **IP 地址**（如 `95.216.123.456`）

### 第 2 步：获取 Polymarket API 密钥（2分钟）

1. 登录 [https://polymarket.com](https://polymarket.com)
2. 右上角头像 → **Profile** → 找到 **API Keys** 部分
3. 点 **Create API Key**，会生成三个值：
   - `API Key`
   - `Secret`  
   - `Passphrase`
4. 把这三个值复制保存好（只显示一次！）

### 第 3 步：获取 MetaMask 私钥（1分钟）

1. 打开 MetaMask 插件
2. 点账户名旁边的三个点 → **Account Details**
3. 点 **Show Private Key**，输入钱包密码
4. 复制私钥（格式：`0x1a2b3c...`，64位十六进制）

> ⚠️ **私钥只放在服务器的 .env 文件里，不要发给任何人，不要截图，不要存在聊天记录里**

### 第 4 步：SSH 登录服务器，配置密钥

```bash
# 连接到服务器
ssh root@你的服务器IP

# 安装脚本（复制粘贴运行）
curl -fsSL https://raw.githubusercontent.com/placeholder/setup.sh | bash
# 如果上面不可用，用本地脚本：
# scp deploy/setup_server.sh root@你的IP:/tmp/ && ssh root@你的IP 'bash /tmp/setup_server.sh'

# 填写密钥
nano /opt/lol-bot/.env
```

在 nano 里按照这个格式填写：
```
PRIVATE_KEY=0x你的MetaMask私钥
POLYMARKET_API_KEY=你的API_Key
POLYMARKET_API_SECRET=你的Secret
POLYMARKET_API_PASS=你的Passphrase
BANKROLL=500
MAX_DAILY_LOSS=50
DRY_RUN=true
```

按 `Ctrl+X` → `Y` → `Enter` 保存

## 常用命令速查

```bash
# 查看机器人状态
systemctl status lol-bot

# 看实时日志
tail -f /opt/lol-bot/data/bot.log

# 重启机器人
systemctl restart lol-bot

# 停止机器人
systemctl stop lol-bot

# 查看今天触发的所有信号
cat /opt/lol-bot/data/bot_signals.jsonl | python3 -m json.tool | grep -A5 '"triggered": true'

# 查看所有交易记录
cat /opt/lol-bot/data/bot_trades.jsonl
```

## 开启真实交易

测试运行几天、确认信号合理后：

```bash

nano /opt/lol-bot/.env
# 把 DRY_RUN=true 改为 DRY_RUN=false

# 重启
systemctl restart lol-bot
```
