## 第一步：准备密钥文件（10分钟）

打开文件 `.env`（在项目根目录），按照说明填入以下信息：

### 1A. MetaMask 私钥
1. 打开 Chrome，点右上角 MetaMask 小狐狸图标
2. 点账户名称旁边的 **三个点**（...）
3. 点 **Account Details**
4. 点 **Show Private Key**
5. 输入你的 MetaMask 登录密码
6. 复制那串以 `0x` 开头的字符串
7. 粘贴到 `.env` 文件的 `PRIVATE_KEY=` 后面

### 1B. Polymarket API 密钥
1. 打开 [https://polymarket.com](https://polymarket.com)，确保已登录
2. 右上角头像 → **Profile**（或直接访问 https://polymarket.com/profile）
3. 找到页面上的 **API Keys** 区域
4. 点 **Create New Key** 或 **Generate API Key**
5. 会生成三个值，分别复制到 `.env` 对应位置

## 第二步：选一个服务器（选最简单的）

推荐按难度从低到高：

### 选项 A：PythonAnywhere（最简单，无需 SSH）⭐ 推荐
- 网址：[https://www.pythonanywhere.com](https://www.pythonanywhere.com)
- 费用：$5/月（Hacker 套餐，支持后台任务不间断运行）
- 优点：**全程在浏览器里操作，不需要任何命令行知识**
- 缺点：每月 $5，比 Hetzner 稍贵（Hetzner 是 €4.5）

### 选项 B：DigitalOcean（有网页版控制台，不需要本地 SSH）
- 网址：[https://digitalocean.com](https://digitalocean.com)
- 费用：$6/月
- 优点：有浏览器内置的控制台，不需要安装任何东西
- 缺点：界面稍复杂

### 选项 C：Hetzner（最便宜，但需要 SSH）
- 费用：€4.5/月
- 缺点：需要命令行操作

**我的建议：先用 PythonAnywhere，最简单，出了问题也容易找我帮你。**

---

## 第三步：在 PythonAnywhere 上部署（如果选了选项 A）

1. 注册 [pythonanywhere.com](https://pythonanywhere.com)，选 **Hacker** 套餐（$5/月）
2. 登录后点顶部菜单 **Files**
3. 上传这些文件（从本地项目目录拖进去）：
   - `scripts/13_auto_trader.py`
   - `data/rules/trading_rules.json`
   - `data/game_winner_markets/game_winner_markets.json`
   - `.env`（已填好密钥的那个）
4. 点顶部菜单 **Consoles** → **Bash console**
5. 在出现的终端里粘贴以下命令（复制全部，一次粘贴）：

```bash
pip install py-clob-client python-dotenv requests && echo "安装完成"
```

6. 安装完成后，点 **Tasks**（顶部菜单）→ **Always-on tasks**
7. 命令填写：`python3 /home/你的用户名/13_auto_trader.py`
8. 点 **Create**，机器人开始运行

## 完成后验证

在 PythonAnywhere 的 Bash console 里运行：
```bash
tail -f /home/你的用户名/data/bot.log
```

如果看到每 30 秒有输出，说明机器人在正常运行。
